# 排版规范（Format Spec）

本文件是「什么样的输出才算合格」的判定标准，与 `prompt.md` 配套：`prompt.md` 是写给模型的指令，
本文件是给人（以及复核的 Agent）看的验收清单。两者冲突时以 `prompt.md` 为准。

## 1. 输出契约

| 项 | 要求 |
| --- | --- |
| 形态 | 单个 HTML **片段** |
| 禁止外壳 | `<html>` `<body>` `<head>` `<!DOCTYPE>` |
| 禁止围栏 | ```` ```html ```` 代码块标记 |
| 禁止解释 | 「以下是整理后的内容」之类的前后语 |
| 编码 | UTF-8，中文标点保持原样（不转成全角/半角互换） |

## 2. 结构约定

- 题干：一个 `<p>` 一段。
- 选择题选项：**每个选项一个 `<p>`**，形如 `<p>A. 3</p>`。不要用 `<ol>`，也不要用 `<br>` 串成一行——
  按 `<p>` 切分是后续「选项抽取」「分页测量」的前提。
- 原文自带答案与解析：规范成 `<p><strong>答案：</strong>…</p>`、`<p><strong>解析：</strong>…</p>`。
- 原文没有答案与解析：输出里**不许出现**这两个词（见 `answer-leak.md`）。
- 允许的标签：`p` `strong` `em` `u` `br` `ul` `ol` `li` `h2` `h3` `blockquote` `table` `thead` `tbody` `tr` `td` `th` `code` `pre` `img`。
- 不写内联 `style`：落库前会被安全消毒器剥掉，写了也会丢。

## 3. 公式约定（最容易出错的部分）

### 定界符

| 场景 | 写法 |
| --- | --- |
| 行内公式 | `$x^2$` |
| 独立成行 | `$$\dfrac{1}{2}$$` |
| 已禁用 | `\(...\)`、`\[...\]`、`` `x^2` `` |

> `\(...\)` / `\[...\]` 虽然能渲染，但统一转成 `$` 形式，否则同一份内容里会出现两套定界符，
> 后续清洗与校验都要各写一份逻辑。`clean` 与 `repair` 都会自动转换。

### 命令速查

| 语义 | 正确写法 | 常见错误 |
| --- | --- | --- |
| 分式 | `\dfrac{a}{b}` | `a/b`、`frac{a}{b}` |
| 根号 | `\sqrt{x}`、`\sqrt[3]{x}` | `√x` |
| 上标 | `x^{2}` | `x²` |
| 下标 | `a_{1}` | `a1`（丢下标语义） |
| 不等号 | `\ge` `\le` `\ne` | `≥` `≤` `≠` |
| 乘除 | `\times` `\div` `\cdot` | `×` `÷` `·` |
| 集合 | `\in` `\notin` `\subset` `\subseteq` `\cup` `\cap` | `∈` `⊂` `∪` `∩` |
| 希腊字母 | `\alpha` `\beta` `\theta` `\lambda` `\pi` `\sigma` `\varphi` | `α` `β` `θ` |
| 几何 | `\angle` `\perp` `\parallel` | `∠` `⊥` `∥` |
| 推理 | `\therefore` `\because` | `∴` `∵` |
| 箭头 | `\to` `\Rightarrow` `\Leftrightarrow` | `→` `⇒` `⇔` |
| 求和/连乘 | `\sum` `\prod` `\int` | `∑` `∏` `∫` |
| 无穷 | `\infty` | `∞` |

### 硬性禁令

1. 公式内部不得出现 Unicode 数学符号。
2. `$` 只作定界符，正文里不得出现裸 `$`（价格写成 `\$` 或「美元」）。
3. 不改数字、条件、符号——排版不是改题。

## 4. 常见输入 → 期望输出

**输入**（纯文本，从 Word 或聊天记录粘来的典型形态）

```
已知f(x)=x²-2x+3，求f(2)的值。
A.1 B.3 C.5 D.7
```

**输出**

```html
<p>已知 $f(x)=x^{2}-2x+3$，求 $f(2)$ 的值。</p>
<p>A. 1</p>
<p>B. 3</p>
<p>C. 5</p>
<p>D. 7</p>
```

**输入**（原文自带解析）

```
求√(x+1)的定义域。
答案：x≥-1
解析：被开方数非负。
```

**输出**

```html
<p>求 $\sqrt{x+1}$ 的定义域。</p>
<p><strong>答案：</strong>$x \ge -1$</p>
<p><strong>解析：</strong>被开方数非负。</p>
```

## 5. 已知边界

- **本地修复只处理已包裹的公式**。`repair` 的 Unicode→LaTeX 替换发生在 `$...$` / `$$...$$` 内部；
  正文里裸露的 `x²≥0` 不会被自动包裹（判定「哪一段算公式」需要语义理解，规则做不到）。
  遇到这种输入，先走 AI 排版，或人工补定界符后再 `repair`。
- **不负责图片**。原文里的图片链接会原样保留；图片上传、缩放、对齐属于宿主应用。
- **不负责题号**。原文的「1.」「（1）」保持原样，不重新编号。
