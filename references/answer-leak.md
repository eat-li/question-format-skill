# 防泄题：为什么「只整理不新增」要靠代码兜底

## 问题

提示词里写「不许新增答案」并不够。实测中模型仍会做两件事：

1. 把题干里的隐含结论写出来：「已知 `f(x)=x^2`，求 `f(2)`」→ 在末尾补一段「答案：4」。
2. 把「解析」理解成任务的一部分，主动补一段解题过程。

题干会被题库列表、作业预览、PDF 导出、家长端页面**直接展示**。多写一段答案，
等于把答案推给了还没做题的学生——这是功能性事故，不是风格问题。

## 解法：字段身份 + 确定性截断

排版请求必须带上 `field`，告诉处理链「这段内容属于哪个字段」：

| field | 含义 | 截断行为 |
| --- | --- | --- |
| `stem` | 题干 | 输出里凭空出现的答案解析 → 删除 |
| `body` | 补充说明 | 同上 |
| `answer` | 答案与解析 | 整段本来就是答案 → **原样放行** |
| `auto` | 未声明 | 与 `stem` 同策略（宁可误删，不可泄露） |

判定顺序（`src/strip-answer.mjs`）：

1. `field === 'answer'` → 直接返回，一个字都不动。
2. 原文出现**真正的答案标记**（【答案】/【解析】/【解答】、`答案：`、`答案是`、`答案为`、
   单独一行的「答案」等）→ 直接返回。原文自带答案说明这是老师有意写的，由模型负责规范化格式，不做删除。
3. 原文没有这些标记 → 输出里出现的答案段落都必然是模型加的：
   - 按块级标签切开，找到第一个**以答案标记开头**的段落，从那一段起整段截掉；
   - 若答案跟正文在同一段（`…求 f(2) 的值。答案：4`），从标记处截断，**保留句末标点**，
     逗号则一并丢掉，避免题干末尾留下孤零零的逗号；
   - 截断可能切在标签中间，用栈配平补齐未闭合标签。
4. 截完为空 → 返回空串，由调用方报错：「AI 返回的内容全是原文里没有的答案解析」。

### 为什么原文判定不看裸子串

旧版只要原文出现「答案」或「解析」任意子串就整体放行。数学题干里的 **「解析式」「解析几何」**
会因此关闭整条防泄题链路——实测「求函数的解析式。」配上模型补的「答案：y=2x+1」会原样保留。
现在要求冒号 / 「是」「为」/【】/ 单独成行，才认为原文真的带了答案。
原文只写「把答案填在横线上」「要求写出解析过程」时，模型补写的答案与解析仍会被删掉。

### 识别哪些答案标记

段首与行内标记覆盖：`答案：`、`解析：`、`解答：`、`故答案为`、`正确答案是`、`故选`、`应选`、
`所以选`、`【参考答案】`；无冒号的 `<strong>答案</strong> 4` 也识别。
行内标记允许跟在句号、分号、问号、感叹号、逗号或 `<br>` 之后。

## 为什么是「开头」而不是「包含」

`ANSWER_HEAD_RE` 只匹配段落开头。若用「包含」，`…求 f(2) 的值。答案：5`
这种把答案跟在正文后面的段落会被整段删掉，题干一起没了——误删比漏删更难发现。
